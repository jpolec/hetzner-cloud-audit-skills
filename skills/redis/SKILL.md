# Redis Security Audit

Use read-only configuration/runtime evidence. Never issue write, flush, configuration, module, replication, script, shutdown, or benchmark commands. Do not collect credential values.

Collect bind addresses, port/TLS port, protected mode, ACL user capability summaries, legacy authentication presence, dangerous-command permissions, persistence/backup state, container publications, and network edges. Correlate Hetzner and host controls before claiming exposure.

Confirm only when a reachable client, listener, applicable controls, and impact are established. Broad bind plus disabled protected mode plus no authentication remains `needs_validation` until the network path is known. Prefer ACL restriction over command renaming. Return facts, candidates, and verifier-ready evidence.
