# Redis audit module

Use read-only configuration/runtime evidence. Never issue write, flush, configuration, module, replication, script, shutdown, or benchmark commands. Do not collect credentials.

Collect bind addresses, ports/TLS, protected mode, ACL capability summaries, legacy-auth presence, dangerous-command permissions, persistence/backup state, container publications, and network edges. Correlate provider and host controls before claiming exposure. Broad bind plus protected mode off plus no authentication remains `needs_validation` until reachability is known. Prefer ACL restriction over command renaming.
