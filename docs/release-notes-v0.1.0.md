# v0.1.0 release notes (draft)

Initial alpha release of an independent, agent-first security-audit toolkit for Hetzner infrastructure.

Highlights: GET-only cloud inventory, normalized evidence schemas, lightweight attack graph, 16 rule IDs across cloud/network/IaC/Docker/PostgreSQL/Redis/backup/CVE context, three-state verification, deterministic coverage ledger, JSON/Markdown/SARIF, seven focused skills plus the orchestrator, and a 33-problem synthetic benchmark.

This is not production-ready. Linux/SSH collection, full Terraform parsing, full database catalog collection, and independent agent orchestration remain procedural skills rather than complete adapters. MCP is deferred.
